# Mellow v3.5 Fix

Fixes for [Mellow](https://modrinth.com/shader/mellow) 3.5 by TheCMK with Voxy on
Minecraft 26.3: the "Uploading texture" / `Close the existing render pass` crash, a
compile error with Water Texture Mode 2, compiler warnings in chat, and translucent LOD
depth reads. Also fixes the flashing sky on Minecraft 26.2 without Voxy.

Not an official Mellow release and not affiliated with TheCMK. The first commit is the
unmodified 3.5 release, so the commit diff shows every change; each one is also marked
`[voxy-fix]` in the shader files.
